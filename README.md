# inkuru

Android manga reader built with Expo SDK 58.

## Requirements

- Bun 1.4+
- Node.js LTS
- Expo Go (Google Play, SDK 58)

## Setup

```bash
bun install
bun run android
```

## Stack

- Expo SDK 58, React Native 0.88, TypeScript 6 (strict)
- Tailwind CSS v4 via [uniwind](https://docs.uniwind.dev/)
